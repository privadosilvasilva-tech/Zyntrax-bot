# Andry's Grand Vision

🚀 PROMPT MASTER — RECONSTRUÇÃO COMPLETA DO SITE BY ANDRY



Quero que você atue como um desenvolvedor Full Stack sênior, arquiteto de software, especialista em UX/UI, animações, aplicações web modernas, banco de dados, segurança, responsividade, acessibilidade e performance.



Sua missão é transformar o projeto atual BY ANDRY em uma experiência web profissional, moderna, extremamente bem acabada e com identidade visual própria, sem parecer um template genérico de IA.



---



📌 CONTEXTO DO PROJETO



O projeto já existe.



- O código está no GitHub.

- O projeto atualmente está hospedado no Render.

- NÃO quero simplesmente criar outro projeto do zero.

- Primeiro analise cuidadosamente o projeto existente.

- Preserve o que estiver funcionando corretamente.

- Reestruture, corrija e evolua o que for necessário.

- Antes de alterar arquivos importantes, compreenda a arquitetura atual.



Se houver funcionalidades existentes que sejam boas, mantenha-as e melhore-as.



---



🎯 OBJETIVO PRINCIPAL



Quero transformar o BY ANDRY em um site que pareça ter sido desenvolvido por uma equipe profissional de desenvolvimento e design, com:



- Design moderno

- Identidade visual exclusiva

- Animações suaves e sofisticadas

- Microinterações

- Transições cinematográficas, mas sem exageros

- Excelente experiência em celular

- Excelente experiência em computador

- Interface intuitiva

- Carregamento rápido

- Código organizado

- Componentes reutilizáveis

- Boa acessibilidade

- SEO bem estruturado

- Segurança adequada

- Arquitetura preparada para futuras funcionalidades



O resultado deve ser impactante sem ficar poluído.



---



🎨 DIREÇÃO VISUAL



Crie uma identidade visual própria para o BY ANDRY.



Não utilize aparência genérica de template.



Quero:



- Tipografia moderna

- Hierarquia visual muito clara

- Espaçamento profissional

- Cards sofisticados

- Bordas e sombras bem utilizadas

- Gradientes sutis quando fizer sentido

- Efeitos de profundidade

- Backgrounds modernos

- Elementos visuais dinâmicos

- Hover effects

- Microinterações

- Animações de entrada

- Animações durante navegação

- Estados de loading

- Estados vazios

- Estados de erro

- Feedback visual para ações do usuário



As animações devem ser fluidas e rápidas, sem prejudicar performance ou usabilidade.



---



📱 RESPONSIVIDADE



O site deve ser desenvolvido com abordagem mobile-first.



Teste e adapte a interface para:



- Celulares pequenos

- Celulares grandes

- Tablets

- Notebooks

- Monitores grandes



Nada pode ficar:



- cortado

- sobreposto

- fora da tela

- pequeno demais

- difícil de clicar

- ilegível



Os menus, cards, botões, textos, imagens e animações devem se adaptar automaticamente ao tamanho da tela.



---



🧭 EXPERIÊNCIA DE NAVEGAÇÃO



Crie uma navegação extremamente intuitiva.



O usuário deve entender rapidamente:



1. Onde está

2. O que pode fazer

3. Como voltar

4. Como acessar outras áreas

5. Qual ação é mais importante



Utilize:



- Navbar moderna

- Menu mobile bem elaborado

- Transições entre páginas

- Breadcrumbs quando fizer sentido

- Botões com estados visuais

- Feedback após ações



Evite navegação desnecessariamente complicada.



---



🎵 SISTEMA DE MÚSICA



O projeto deve possuir um sistema de música integrado à experiência do site.



Quero que a música possa:



- Iniciar automaticamente quando tecnicamente permitido pelo navegador

- Continuar tocando enquanto o usuário navega pelo site

- Não reiniciar desnecessariamente a cada mudança de página/rota

- Possuir botão claramente visível para pausar

- Possuir botão para continuar

- Possuir controle de volume

- Mostrar visualmente quando a música está tocando

- Respeitar a preferência do usuário



IMPORTANTE:



Navegadores modernos podem bloquear autoplay com áudio. Portanto, implemente o comportamento da forma tecnicamente correta:



- Tente iniciar automaticamente quando permitido.

- Caso o navegador bloqueie, aguarde a primeira interação do usuário e então inicie.

- Nunca force áudio contra a vontade do usuário.

- A preferência de música do usuário deve ser preservada durante a sessão e, quando apropriado, usando armazenamento local.



O player deve ser bonito e integrado ao design, não parecer um elemento colocado aleatoriamente na página.



---



✨ ANIMAÇÕES



Utilize animações modernas e profissionais.



Exemplos:



- Fade in

- Slide

- Scale

- Blur transitions

- Parallax sutil

- Hover

- Scroll reveal

- Animações de cards

- Transições entre estados

- Feedback de clique

- Loading animations

- Transições suaves entre páginas



NÃO coloque animações em absolutamente tudo.



A regra é:



animação deve melhorar a experiência, não distrair o usuário.



Respeite também "prefers-reduced-motion" para usuários que preferem reduzir animações.



---



⚡ PERFORMANCE



Priorize performance desde o início.



Implemente quando apropriado:



- Lazy loading

- Code splitting

- Otimização de imagens

- Compressão

- Componentes eficientes

- Evitar renders desnecessários

- Evitar bibliotecas desnecessárias

- Carregamento progressivo

- Cache adequado



Não sacrifique performance apenas para adicionar efeitos visuais.



---



🔐 SEGURANÇA

Não exponha:



- API keys

- Secrets

- Tokens

- Credenciais

- Variáveis privadas

- Informações sensíveis



Utilize variáveis de ambiente quando necessário.



Valide entradas do usuário.



Se houver banco de dados:



- Configure regras de acesso apropriadas.

- Evite acesso indevido.

- Utilize autenticação quando necessário.

- Nunca confie apenas na validação do frontend.



---



🗄️ BANCO DE DADOS E BACKEND



Se o projeto atual já utilizar backend ou banco de dados:



1. Analise a estrutura existente.

2. Preserve os dados existentes.

3. Não apague tabelas ou informações sem necessidade.

4. Melhore a arquitetura quando necessário.

5. Corrija problemas de segurança.

6. Garanta tratamento adequado de erros.



Se uma funcionalidade realmente precisar de backend, implemente-a corretamente em vez de criar apenas uma simulação visual.



Não crie dados falsos fingindo que são dados reais.
